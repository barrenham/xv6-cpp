# 动态 RAM 挂载

```sh
mount
mkdir /tmp/work
mount -t ramfs /tmp/work
echo hello > /tmp/work/file
cat /tmp/work/file
umount /tmp/work
```

`mount` 无参数列出挂载类型和路径，普通用户也可以查看。新增挂载和卸载仅允许有效 UID 为 0 的进程执行。当前支持类型为 `ramfs` 的独立内存文件系统，挂载点必须是已有目录，使用规范绝对路径，不含重复斜杠、`.`、`..` 或结尾斜杠。挂载根为 root:root 0755，需要开放给其他用户时可再 chmod/chown。

全局挂载表最多 7 项：启动时固定的 `/dev`、`/proc`、`/tmp`，以及最多 4 个动态实例。固定挂载受保护，不能卸载。没有挂载命名空间、bind mount、磁盘分区发现或延迟卸载；不能在一个已经挂载的根上继续叠加挂载。

挂载覆盖目录原有内容，不删除原内容；卸载后底层内容重新可见。动态 RAM 中的文件在卸载时全部丢弃，不写入磁盘。支持在动态 RAM 中建立子挂载，需要先卸载子挂载。

## 生命周期与并发

VFS 使用命名空间 SleepLock，路径遍历取得稳定 inode 引用后才释放它；create/link/unlink/rename 和挂载表修改使用相同锁。锁内按后端执行节点操作，不在持自旋锁期间等待目录 I/O。路径系统调用先取得日志事务，再进入命名空间锁，保持锁顺序一致。首个进程在调度之前直接取得磁盘根引用，避免提前使用需要进程上下文的睡眠锁。

每个动态实例有独立的树锁、引用锁、编号位图和节点链表。外部引用总数不计目录指向父节点的内部固定引用；根的初始化引用及挂载表引用共两个。打开文件、cwd、未删除路径查找引用、已删除但仍被持有的目录，以及子挂载的覆盖点/父节点引用都会使实例忙碌。只在外部引用回到根的两个固定引用时才允许卸载。

卸载期间命名空间锁阻止新路径进入，树锁等待已完成引用扣减但仍在回收的操作退出。随后遍历节点链表销毁全部数据页、目录页和节点页，清空位图并释放实例槽。分配挂载根失败时返回错误，释放预先取得的覆盖点和父节点引用，不发布半成品挂载。

`mount_info` 共享结构包含 path[128] 和 type[32]。`mountinfo(index, &info)` 返回 1 表示一条记录，0 表示枚举结束，-1 表示参数或复制错误；并发挂载变化时逐条枚举不保证整表快照。`mount(type, path)` 与 `umount(path)` 返回 0/-1。
