# 路径与文件工具

```sh
pwd
cp /usr/share/doc/xv6/README /tmp/readme
mv /tmp/readme /tmp/notes
mkdir /tmp/archive
mv /tmp/notes /tmp/archive
```

`pwd` 调用运行库 getcwd，从当前 inode 沿父目录查找真实路径，与 shell 提示符共用实现。它不依赖 PWD 环境变量，跨挂载点和目录重命名后仍查询当前路径。实现需要读取父目录；目录已删除、祖先不可读或查找缓冲不足时返回错误。

`cp source destination` 复制普通文件，支持把目标指定为已有目录。复制处理短读写并在失败时返回非零；在截断目标前比较 device/inode，拒绝把文件复制到自身或硬链接别名。新文件遵守当前 umask，已有目标保持原有属主和权限。当前不支持递归复制、多个源文件或 cp 的选项；复制失败时可能留下部分目标内容。

`mv source destination` 在同一文件系统内调用 rename，支持普通文件、目录及目标目录。替换目标必须类型兼容，被替换的目录必须为空。打开的旧目标继续引用原 inode；移动目录会更新父目录和链接计数，已有 cwd 随目录移动。

跨文件系统只支持普通文件的复制后删除，复制完整成功后才 unlink 源文件；这个过程不具备原子性。跨文件系统目录移动不支持。

## rename

共享用户 ABI 为 `rename(old_path, new_path)`。VFS 的命名空间睡眠锁串行化路径遍历、挂载关系及目录修改。重命名拒绝跨后端、点目录、目录环、挂载点及包含挂载的祖先；同时检查源/目标父目录写与执行权限、sticky 属主约束。源和目标是同一个 inode 时成功且保留两处名字。

磁盘后端在单个日志事务内安装目标项、删除原项并更新父目录信息；原地改名复用原目录槽。RAM 后端在树锁内更新槽位和父节点引用。目标资源不足时保留源项；重命名本身不复制文件内容。

workflow 单核/五核测试覆盖工具调用、目标替换、打开的旧目标、硬链接、自环拒绝、目录移动和新父目录；同时覆盖磁盘和 RAM 后端。

## 文件偏移、截断和落盘

| 用户接口 | 行为 |
| --- | --- |
| `lseek(fd, offset, SEEK_SET/CUR/END)` | 返回新的字节偏移；错误不推进偏移；dup/fork 的同一次打开共享偏移 |
| `ftruncate(fd, size)` | 需要可写普通文件描述符；缩短释放页/磁盘块并清除尾部，增长部分读为零；不改变描述符偏移 |
| `fsync(fd)` | 等待日志提交并发出后端落盘请求；RAM 普通文件成功返回，管道/终端不支持 |
| `O_APPEND` | 每次写入分块在 inode 锁内先取 EOF，独立 open 的追加写也不会互相覆盖；可通过 F_SETFL 修改 |

磁盘允许在 EOF 后写入，未分配的区间作为稀疏空洞读取为零，读取空洞不分配磁盘块。磁盘单文件仍受 MAXFILE 限制；RAM 文件按需增长。截断后原有打开偏移保持不变，因此之后的写入可以重新建立补零间隔。

`fsync` 当前保守地等待系统盘及已连接数据盘的相关日志批次，再 flush 所属后端。它可能一并提交其他文件的事务；不是仅刷新某个文件块的细粒度实现。VirtIO 支持 FLUSH 时，在设备确认 flush 完成后才返回；宿主机仍需正确实现持久存储语义。

`cp` 打开目标后先 fstat 校验描述符，再 ftruncate，避免在路径检查和 open 之间目标被替换为源文件硬链接时提前破坏源内容。

`storagecheck` 分别在磁盘和 RAM 上检查偏移共享、负偏移、稀疏空洞、缩短再增长、只读 fd 拒绝截断、并发追加和不支持 seek/sync 的管道。
