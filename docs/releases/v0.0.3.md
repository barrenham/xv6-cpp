# v0.0.3

2026-11-01。本版本在 v0.0.2 基础上加入 VNC 图形终端、共享 framebuffer 映射与 GPU 视口滚屏，并更新内存、文件系统、调度和用户程序。

## 主要变化

- VirtIO GPU 2D 显示、GPU 完成中断和睡眠唤醒，支持配置 640×480 至 1920×1080 可见分辨率，默认1280×800。
- fbterm 提供灰度等宽 ASCII 字体、PTY shell、VNC/串口键盘输入、VirtIO 键盘与滚轮、1024行历史和 PageUp/PageDown；修复折行、滚屏及嵌套 PTY 的逐层 Ctrl-] 退出。
- 独立显示进程接收有界字符快照，主进程继续处理 PTY 和输入；批量输出合并更新，支持关闭串口镜像。
- 设备专用 mmap 式共享显存：用户态直接写 GPU backing 页，支持 fork 共享、exec 清理、显式解除和失败回滚，取消用户→内核像素复制。
- 两屏高 GPU 资源通过移动 scanout 复用旧行，只上传变化区域；窗口越界时回卷重绘，并保留离屏内容宽度边界以擦除旧长行。
- 集成 ext3 持久根盘，整理可扩展 proc/dev 提供者；增加 ping、缓冲输出的 curl、clear 和用户程序安装说明。
- 统一虚拟地址区域管理，加入可扩展调度及多态 slab 分配；优化内存填充和对齐机器字复制，保留重叠与边界语义。
- 使用可复用 C++20 控制图表达内核工作流，维护编译器语义绑定、函数文档及原生 clangd 索引。

## 性能与范围

五核、1920×1080、每组两轮固定60次单行滚屏：

| 指标 | 复制缓冲与 CPU 搬行 | 共享显存与 GPU 视口 |
| --- | ---: | ---: |
| 循环耗时中位数 | 2.691秒 | 0.406秒 |
| 每轮用户→内核像素复制 | 127.01 MB | 0 |
| 每轮 GPU 资源上传 | 127.01 MB | 6.74 MB |

上述数据来自共享显存功能提交 `3c31d0e`；本次版本号更新未改变绘制路径。
固定测试绕过合帧节流，不能据此推算交互刷新率。2000行批量输出的总耗时没有改善；文本解析、PTY、调度及中间帧数量仍有开销。零拷贝指用户到内核的像素路径，QEMU资源传输和VNC编码仍需处理。

当前字体不包含中文；未实现通用文件 mmap、VirGL/3D、垂直同步或多窗口合成。共享资源的并发绘制由应用协调。完整方法、原始数据和限制见[共享显存及 GPU 优化](../mapped-gpu.md)。

## 使用与升级

已有根盘先退出使用它的QEMU，再执行：

```sh
cmake --preset dev
cmake --build build/dev --target rootfs-update
cmake --build build/dev --target qemu-vnc
```

离线更新会备份根盘并保留账户、密码和用户文件；不要重新创建已有根盘。VNC默认监听 `0.0.0.0:5901`。登录root后运行：

```sh
fbterm --no-serial-mirror
```

共享显存及GPU视口滚屏默认启用。源代码发布不包含开发者的持久根盘、备份或账户数据。另见[图形显示](../graphics.md)、[图形终端](../fbterm.md)及[rootfs工具](../rootfs-tools.md)。
