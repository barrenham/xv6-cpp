# v0.0.4

本版本加入运行时全局调度策略切换，并汇总线程、FS 工作池、设备热插拔与终端工具的更新。

- `schedctl` 在 CFS、MLFQ 和 round-robin 间切换，无需重启。内核验证修改权限，并在共享队列锁下迁移实体，保留实际 CPU 时间、权重及任务所有权；查询返回一致状态快照。
- CFS 按虚拟运行时间和权重安排执行，MLFQ 支持三层额度、高优先级任务抢占及周期提升。开机仍使用 CMake 选定的默认策略。
- 加入内核线程及 pthread 运行库、FS 后端线程池与服务恢复相关能力。
- PCIe e1000 支持运行中插入、自动绑定、安全拔除、网络状态撤销和实例资源回收。
- 新增 `poweroff` 和 `reboot`，同步已挂载文件系统后关机或重启。
- 统一用户命令的终端样式，加入简易 Vim，并改善常用命令的输出路径。

运行时调度切换不持久化到启动配置。CFS 是本系统的轻量实现；未实现 Linux 的 EEVDF、cgroup 或逐核负载均衡。

本版本在线切换、进程所有权及电源管理的 9 项原生/QEMU 检查通过。单核与五核均完成并发进程、pthread、文件 I/O、睡眠及两个控制线程共同切换的压力场景，并验证了切换后的重启和持久磁盘完整性。
