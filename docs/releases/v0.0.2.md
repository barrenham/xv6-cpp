# v0.0.2

本版本在 v0.0.1 基础上加入独立 rootfs 工具、IPv4 防火墙，并整理网络层的职责和资源契约。

## 主要变化

- `rootfs-create` 从干净种子创建独立根盘，由使用者首次启动设置自己的密码。
- `rootfs-update` 离线更新受管程序，保留账户和用户文件，提供容量预检、文件锁、完整备份及原子替换。
- 新增 `iptables`：filter 表、INPUT/OUTPUT、自定义链、CIDR/协议/端口/接口匹配、跳转/返回和计数。规则由现有 netctl 管理，修改要求 root；规则不自动持久化。
- 路由表独占路由记录；`AddressConfiguration` 统一手工与租约地址的联合配置事务。
- TCP 编解码通过接收契约连接注册表，连接分派及待接受子连接归属由注册表管理，发送对象显式注入。
- `Ipv4Reassembly` 独立管理重组队列、重叠检测、容量和超时。普通 IPv4 与 DHCP 广播复用首部构造及 OUTPUT 检查。
- `Packet::Context` 在移动、克隆、队列恢复和重组中保留隧道处理预算；整层命名、格式和函数文档同步整理。

## 验证

- 内核与宿主机契约程序构建通过，全部 21 项网络标签测试通过。
- 完整 87 项回归首次通过 86 项；`ram_2048MiB` 在网络初始化前等待物理分配器启动标记超时。同一内核随后单独复测及连续三次复测均通过，首次超时原因尚未确定。
- 新增原生契约覆盖双 TCP 协议栈隔离、backlog、监听关闭、满表租约替换、Packet 上下文及重组页面回收。
- 仓库格式检查、函数文档覆盖与真实 clangd 悬浮验证通过；原生悬浮的已知限制见函数文档说明。

## 使用与范围

已有根盘的用户程序需在退出 QEMU 后执行 `cmake --build build/dev --target rootfs-update` 更新。源码不包含开发者的根盘、备份或账户数据。

当前防火墙不包含 NAT、连接跟踪、FORWARD 或 IPv6，重启恢复空规则及默认 ACCEPT。完整功能和使用限制分别见 [rootfs 工具](../rootfs-tools.md)、[防火墙](../network-firewall.md)、[网络结构](../network.md) 与 [函数文档](../functions/README.md)。
