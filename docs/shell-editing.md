# shell 输入编辑

交互 shell 在读取一行期间临时关闭 ICANON、ECHO、ISIG 和 IEXTEN，输入交给用户态 Editor；返回命令、遇到 EOF 或读取错误时，析构恢复进入前的 termios。执行普通程序之前终端已经恢复，程序可以继续自行使用规范模式或原始模式。输入来自管道、或用户通过 stty 主动关闭规范模式/回显时，沿用原来的读取方式。

| 按键 | 行为 |
| --- | --- |
| ↑ / ↓ | 浏览最近 32 条命令；回到末尾恢复尚未提交的草稿 |
| ← / → | 移动插入位置 |
| Home / End、Ctrl-A / Ctrl-E | 移到行首/行尾 |
| Backspace、Delete | 删除前一个/当前字符 |
| Ctrl-U | 清空整行 |
| Ctrl-C | 取消当前输入并重新显示提示符 |
| Ctrl-D | 空行退出 shell；有内容时删除光标处字符 |
| Tab | 补全命令或路径 |

QEMU 串口默认占用 Ctrl-A 作为控制前缀，需要连按两次 Ctrl-A 才会向客体发送一次。编辑使用 ANSI 清行和退格定位，适用于支持 ANSI 的终端。当前按字节编辑，没有多字节字符宽度计算或跨屏自动换行布局。

历史只存放在所属 shell 的内存中，退出后消失，连续重复命令不会重复记录。输入文本最多 510 字节，另留换行和 NUL；历史和补全缓冲不放在单页用户栈上。

首个命令词从 shell 内建及 PATH 目录搜索，其余参数从当前目录搜索；带斜杠的词在指定目录搜索。目录补全追加 `/`，唯一普通文件追加空格，多候选补全公共前缀，再次 Tab 列出候选。最多保留 128 个去重候选，达到上限时只列出结果、不插入不确定的公共前缀。带引号、转义和 shell 特殊字符的词不做自动补全，也不列出需要转义的文件名。

SIGCHLD 自管道仍唤醒输入循环。后台作业状态变化后，shell 清行、重画用户名/路径/当前输入，并恢复光标位置；前台程序的信号和作业控制流程保留。

实现位于 `user/apps/sh/editor.cpp`；session 单核/五核测试覆盖插入、历史草稿、行首/行尾、命令与文件补全、取消输入和嵌套 shell 退出。

提交命令时先恢复终端，再输出换行，避免用户看到换行后立即输入下一程序的数据仍被编辑模式接收。命令列表和管道的协调进程使用 waitpid 的编码状态，重试 EINTR，并将信号退出、异常负退出值映射到 128 以上状态；中断左侧命令后不会因旧 wait 的负退出码继续执行分号右侧命令。
