# `kernel/io/fs_mount.h`

用户态挂载管理通道的 Version 2 消息 ABI。`Request` 携带版本、请求编号、原调用者 PID、结果、类型名、挂载路径、可选源和选项；类型名缓冲为 32 字节，路径及源缓冲各为 128 字节，选项为 256 字节。

内核按同一消息尺寸交付请求和接收响应，并核对登记进程、版本、请求编号及原调用者 PID。管理器负责在用户态启动或选择后端，再调用通用挂载入口。管理器用 Progress=-2 报告仍在加载，只续期当前请求的 30 秒无响应期限；最终成功/失败仍为 0/-1，插件自身另有清单启动期限。该结构不携带内核指针，也不指定某种文件系统的磁盘格式。

详见[文件系统服务迁移](../../../fs-service-migration.md)。
