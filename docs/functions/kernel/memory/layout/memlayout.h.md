# `kernel/memory/layout/memlayout.h`

开发职责：物理页所有权、地址范围、页表和用户内存复制。

源码：[打开实际文件](../../../../../kernel/memory/layout/memlayout.h)。文档不会加入源码或生成额外 C++ 声明。

该文件在清点范围内没有独立函数项；它提供模块重导出、类型、常量、宏或布局约束。不要把这些定义误当作可调用程序。


## 格式、边界与使用约定

定义 QEMU virt 的设备窗口、内核装载位置与用户顶端特殊映射。RAM 长度由启动发现流程提供，不能把默认镜像参数当作实际物理内存边界；trampoline、trapframe 和用户 PID 页的权限由映射代码分别建立。
