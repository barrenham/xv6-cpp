## `xv::drivers::E1000::reclaim`

```doxygen
@fn void xv::drivers::E1000::reclaim()
@brief 归还所有已经由硬件确认完成的发送页。
@pre 调用者持有 lock_。
@details 以 acquire 读取 DD；完成项释放一次并清空 transmitted_，描述符留待下一次覆盖。未完成页仍属于硬件，不能提前复用。
```

## `xv::drivers::E1000::transmit`

```doxygen
@fn bool xv::drivers::E1000::transmit(void *page, unsigned length)
@brief 把一个完整以太网帧交给发送 DMA 环。
@param page 可 DMA 的独占物理页，数据从页首开始。
@param length 14 至 1514 字节，不含 Ethernet FCS。
@return true 表示设备取得整页所有权；false 表示调用者仍持有页面。
@details 持锁回收 DD 完成项，环满时立即失败。保留一个空描述符避免 TDT 与 TDH 重合；设置 EOP/IFCS/RS，屏障后推进尾指针。完成中断或后续提交归还页面。
@details 流程由 TransmitFlow::Graph 的编译期策略连接；保留原资源、锁、返回值及事件消费协议。
```

## `xv::drivers::E1000::handle_interrupt`

```doxygen
@fn void xv::drivers::E1000::handle_interrupt()
@brief 确认网卡中断并把已完成接收帧移交协议层。
@details 读取 ICR 清除原因，在设备锁内回收 TX，并检查 RX 的 DD、EOP、错误与长度。成功分配替换页后才取走旧页；内存不足时复用原页并丢包。重设状态并经屏障写 RDT 后释放锁，随后回调接收者，允许 ARP 回包再次进入 transmit。
@note 不持设备锁调用协议层，不在中断中睡眠。
@details 流程由 InterruptFlow::Graph 的编译期策略连接；保留原资源、锁、返回值及事件消费协议。
```

## `xv::drivers::E1000::promiscuous`

```doxygen
@fn bool xv::drivers::E1000::promiscuous(bool enable)
@brief 在设备锁内检查就绪状态并设置或清除 RCTL 的 UPE/MPE 位，执行 I/O 屏障；不修改 MAC、DMA 环或其他接收控制位。
@param enable true 接收任意单播和组播，false 恢复普通过滤。
@return 设备未就绪返回 false，设置成功返回 true。
@pre 调用者不能持网络配置锁。
```
