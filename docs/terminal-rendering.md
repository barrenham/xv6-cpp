# 终端字形、滚屏和跨行编辑

fbterm使用 **XV Mono 10×20** 等宽灰度字形，源自DejaVu Sans Mono的16px
轮廓字体。字符按实际像素比例栅格化，边缘使用16级覆盖率与前景/背景颜色
混合，替换旧的5×7字形仅纵向放大的实现。

| 分辨率 | 字符网格 |
| --- | --- |
| 640×480 | 64×24 |
| 1280×800 | 128×40 |
| 1366×768 | 136×38，右侧6像素、底部8像素填背景 |
| 1920×1080 | 192×54 |

## 滚屏提交

`user/apps/fbterm/render.h` 计算全部脏行的包围矩形，为整块像素准备完毕后，
只调用一次XV_FB_DRAW。驱动仍先复制完整矩形，再transfer/flush；不再把
同一次滚屏拆成多个各自flush的条带。缓冲按实际屏幕申请，1920×1080约
7.91 MiB；分配失败会报告并退出，缓冲不使用用户栈。

栅格化先填背景，再绘制非空字形、彩色背景及光标，避免逐像素重复处理大片
空白。默认字色（前景7、背景0）的95个字形还缓存最终像素，约74.2 KiB，
滚屏时复用已混合的灰度边缘；其他字色和光标仍使用相同的参考栅格器。

### 连续输出合并

`user/apps/fbterm/pacing.h` 调度刷新，替换持续输出时固定约60次/秒的尝试：

- 普通少量输出：从首次待绘制输出起约16ms提交。
- 发生滚屏或本批累计至少4096字节：从首次待绘制输出起最多等100ms，
  或输出安静20ms后提交，两者取较早时间。
- 根据上一次栅格化加XV_FB_DRAW的实际耗时，完成后至少空出3倍耗时再绘制，
  此额外间隔封顶250ms；滚屏/大批输出至少间隔100ms，避免串口背压造成
  分段输出时被20ms安静定时器反复触发。该限速也可能推迟上述普通输入或尾帧的提交。
- 持续有新数据不会重置首次输出时间，因此长流不会无限推迟显示。
  EOF、退出和显式分离直接提交最后一帧，绕过延迟。

只有中间画面被合并；所有PTY字节仍按顺序解析和串口转发。滚屏标志在
成功提交后清除，提交失败时保留。持续密集输出以约10次/秒为目标，实际
频率受绘制耗时、输出间隙、串口背压和调度影响，不承诺固定帧率或CPU占比。
时间基准使用本项目QEMU virt与clockticks测试一致的10MHz timebase。
当前接口没有硬件垂直同步，无法承诺消除所有VNC端的撕裂。

## 自动换行与编辑

原终端到达行尾后保持pending-wrap；第一次换行后未复位该标志，导致后续
每个字符都再次换行。本版在完成一次自动换行后清除标志，并验证连续多行
输入、带SGR的边界和滚屏场景。

shell编辑器从TTY窗口取得列数，记录实际显示的光标行。重绘时回到原输入
区域，清除旧输入行，再恢复多行内容与光标。退格、Home/End、历史和插入
均使用跨行位置；保留终端原有pending-wrap，不额外把输入拆成换行字节。
异步作业通知及补全列表从新行重绘，避免误移到上一个输入区域。

## 字体来源

预生成字形表位于 `user/apps/fbterm/font.h`，普通构建不需要字体库。
原字体散列与参数记录在表头，源代码和分发镜像同时保留字体授权：

- [字体授权](../user/apps/fbterm/FONT-LICENSE.txt)
- 客体文件 `/usr/share/doc/xv6/fbfont.txt`（名称兼容xv6旧文件系统）

可在装有Pillow/FreeType的宿主环境重新生成：

```sh
/usr/bin/python3 tools/generate_fbterm_font.py \
  --font /usr/share/fonts/truetype/dejavu/DejaVuSansMono.ttf \
  --output user/apps/fbterm/font.h
```

栅格器版本会影响结果，生成的表随源码保存。当前仍只提供可打印ASCII字符；
未加入中文、完整Unicode字库或运行期字体加载。

## 验证

`fbterm_contract` 验证字形宽高、灰度边缘、连续跨行输入、整块提交计数、
失败时保留脏标记，以及优化栅格结果与逐像素参考输出的一致性（含背景色、
反显、光标和非整字符边缘）；同一测试使用ASan/UBSan与泄漏检查运行。另以虚拟时钟验证每秒1000个
输出包只触发9次中间提交、安静后的尾帧、连续输出截止时间、耗时反馈和
字节计数饱和，并逐像素核对全部95个默认字色缓存字形。

单核/五核QEMU测试使用QMP读取真实scanout，核对新字形和长行输入、跨行
退格、Ctrl-A/Ctrl-E后追加字符，以及VNC键盘、PTY、EOF/分离和终端状态恢复。
shell作业控制及环境变量的完整回归见上轮验收。单核/五核测试额外执行本地2000行文件的快速输出，核对完整
串口字节和GPU最终的第1999行、结束标记。原fork性能门禁按用户要求跳过，参数未修改。
