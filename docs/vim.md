# 简易 Vim 风格编辑器

系统提供 `/bin/vim`：一个独立的用户态 ELF，使用现有 TTY/PTY、文件和 ANSI 终端接口。它提供 Vim 风格的基本模式与按键，不包含插件、语法高亮、多窗口、可视选择和自动恢复文件。

```sh
vim /root/notes.txt
vim                    # 空白缓冲区，稍后 :w 文件名
vim --help
```

打开后按 `i` 输入，按 `Esc` 回到普通模式，输入 `:wq` 再回车保存退出。根目录盘与支持 create/rename/sync 的用户态 FS 后端都可以使用。

| 模式 | 按键 | 操作 |
| --- | --- | --- |
| 普通 | `h j k l`、方向键 | 左、下、上、右 |
| 普通 | `0` / `$`、Home / End | 行首、行尾 |
| 普通 | `gg` / `G` | 文件开头、最后一行 |
| 普通 | PageUp / PageDown、Ctrl-U / Ctrl-D | 翻页、半页移动 |
| 普通 | `i` / `a` | 光标前、光标后开始插入 |
| 普通 | `I` / `A` | 行首、行尾开始插入 |
| 普通 | `o` / `O` | 下方、上方新建一行并插入 |
| 普通 | `x` / Delete | 删除当前字符 |
| 普通 | `dd` | 删除当前行 |
| 普通 | `u` / Ctrl-R | 单级撤销/重做；再次按键在两个版本间切换 |
| 普通 | `/文字` 回车、`n` | 大小写敏感的字面量查找、下一处；到末尾后回绕 |
| 插入 | 文字、Enter、Tab、Backspace、Delete | 输入、换行、制表、删除、合并行 |
| 插入 | 方向键、Home / End | 移动插入位置 |
| 插入/命令/查找 | Esc、Ctrl-C | 返回普通模式/取消输入 |
| 命令 | `:w`、`:w 文件名` | 保存当前文件、另存为新文件 |
| 命令 | `:wq`、`:x` | 保存并退出；`:x` 在无修改时直接退出 |
| 命令 | `:q`、`:q!` | 无修改时退出、丢弃修改退出 |
| 命令 | `:help` | 显示简短按键说明 |

底部状态行显示模式、文件名、修改标记 `[+]` 和光标行列。内容自动上下及左右滚动；Tab 按 8 列停靠点显示。默认使用原色正文与反白状态栏，没有大面积青蓝色。

## 文件与终端行为

- 文件最大 1 MiB，按字节编辑；支持 ASCII 文本及 Tab/换行，暂不支持中文/UTF-8 光标与字形宽度。原文件中的非 ASCII 字节显示为 `?`，未编辑的字节仍按原样保存。键盘插入限于 ASCII。
- 拒绝含 NUL 的二进制文件、目录、符号链接及有多个硬链接的文件。保留已有的普通权限与属主/属组；保存不继承 setuid/setgid 位。
- 保留末尾有无换行的原始状态，不自动追加换行。单次插入模式会话、删字符/删行各作为一个撤销步骤；只保留一级撤销/重做，保存后清空撤销记录。
- 保存先在同目录创建独占临时文件，完成写入与 fsync、关闭后，再 rename 替换目标。失败时清理自己创建的临时文件，保留原文件与修改中的缓冲区。新目标名已存在时拒绝覆盖，可换一个文件名另存。
- 保存当前文件前检查原 inode 和内容哈希，拒绝覆盖已被替换或内容已变化的文件；不提供并发编辑锁，不保证与其他写入者进行同步事务。
- stdin/stdout 必须是当前前台终端。启动时保存 termios，退出、输入断开或收到已处理的终止信号时恢复。Ctrl-Z 暂不提供挂起/恢复；SIGKILL 无法执行清理。终端尺寸在按键重绘时更新，未知尺寸使用 80×24，支持的画布为 20–240 列、4–100 行。
- 重绘缓存每行文字与反白状态，比较前后内容后只发送变化的字符；仅在行缩短时清除旧尾部。移动光标不会重发未变化的正文。输出仍通过缓冲批量写入，仅首次进入备用屏幕时清屏。支持备用屏幕的串口客户端退出时恢复此前页面；忽略备用屏幕指令的终端会保留最后编辑画面。

文件读写仍经过通用 FS 桥接，编辑器没有为某一种文件系统加入专门接口。由于旧版 open/lstat 不设置 errno，新文件判断会读取父目录确认目标缺失，避免把权限错误误判为新文件。

代码按职责位于 `user/apps/terminal/vim/`：`buffer` 管理文本和撤销，`file` 管理载入与保存，`terminal` 管理串口/PTY 与按键，`editor` 管理模式、视口和命令，`vim.cpp` 管理程序入口。

## 验证

`vim_buffer_contract` 检查行边界、移动、撤销/重做、修改标记及 1 MiB 容量边界。`vim_1cpu/5cpu` 在独立 QEMU 测试盘上实际按键操作，退出后读取磁盘验证保存的字节、权限、撤销、丢弃修改、失败后的另存、长行/翻页、二进制/符号链接拒绝、临时文件清理和 termios 恢复，并运行只读 e2fsck。
